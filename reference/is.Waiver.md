# Is the provided object of type waiver?

Is the provided object of type waiver?

## Usage

``` r
is.Waiver(x)
```

## Arguments

- x:

  A provided `Waiver` object

## Value

Boolean evaluation with [logical](https://rdrr.io/r/base/logical.html)
output.

## Examples

``` r
is.Waiver(new_waiver())
#> [1] TRUE
```
