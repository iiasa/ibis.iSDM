# Set the threads for parallel processing.

Small helper function to respecify the number of threads for parallel
processing.

## Usage

``` r
ibis_set_threads(threads = 2)
```

## Arguments

- threads:

  A [`numeric`](https://rdrr.io/r/base/numeric.html) greater thna `0`.

## Value

Invisible
