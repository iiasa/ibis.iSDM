# Wrap a list with stan model code

engine_stan builds a list with stan model code. This function
concatenates them together.

## Usage

``` r
wrap_stanmodel(sm_code)
```

## Arguments

- sm_code:

  A [list](https://rdrr.io/r/base/list.html) object with exactly 7
  entries.

## Value

A [character](https://rdrr.io/r/base/character.html) object.
